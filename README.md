
# DineWise: A Modern Restaurant Web Experience

A sleek, responsive, and multi-page restaurant website designed to showcase a premium dining experience. This project focuses on intuitive navigation, high-quality visual presentation, and a mobile-friendly layout for food enthusiasts.


## Built With

*   **HTML5:** Structured with semantic elements for better SEO and accessibility.
*   **CSS3:** Custom styling using Flexbox and Grid for complex, responsive layouts.
*   **JavaScript (ES6):** Added for interactive elements and smooth navigation.
*   **Google Fonts:** Carefully selected typography to match the restaurant’s brand identity.

---

## Key Features

*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
*   **Digital Menu:** A beautifully laid out menu section that is easy to read and navigate.
*   **Reservation Interface:** A clean, user-friendly contact and booking layout.
*   **High-Quality Visuals:** Use of optimized imagery and CSS overlays to create a "digital cozy" and appetizing atmosphere.
*   **Smooth Navigation:** Seamless transitions between the Home, About, and Menu sections.

---

##  Technical Focus

### 1. Layout Management
I utilized a mix of **CSS Flexbox and Grid** to handle the restaurant's menu items and gallery, ensuring that the spacing remains consistent regardless of screen size.

### 2. User Experience (UX)
The project prioritizes a "mobile-first" approach, ensuring that potential customers can easily find the location, menu, and contact details while on the go.

### 3. Component Reusability
The CSS was written with modularity in mind, allowing for easy updates to the menu items or gallery images without breaking the site structure.
